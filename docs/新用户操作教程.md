## 一、平台概览

### 1.1 平台是什么
「服务部AI洞察平台」是一个**AI 报告生成与分发平台**：你配置好数据源和提示词，AI 自动抓取网页内容、分析并生成结构化报告，支持导出 PDF/Word/Markdown、邮件分发、历史版本管理与团队共享。

### 1.2 界面布局
登录后看到的整体布局分三块：

```
┌──────────┬────────────────────────────────────┐
│ 左侧菜单  │  顶部栏（平台名 / 主题切换 / 用户菜单） │
│  · 报告中心 │────────────────────────────────────│
│  · 邮件发送记录│  主内容区                        │
│  · 个人中心  │  （当前页面）                     │
└──────────┴────────────────────────────────────┘
```

- **左侧菜单**：报告中心、邮件发送记录、个人中心；部门管理员多「部门管理」，超级管理员多「部门管理」「系统管理」
- **顶部栏**：右侧可切换浅色/深色主题；点击右上角头像可进个人中心或退出登录
- **主内容区**：当前页面主体

### 1.3 三种角色与权限

| 功能 | 普通用户 | 部门管理员 | 超级管理员 |
|---|---|---|---|
| 查看报告（自己的/本部门的/公开的） | ✅ | ✅ | ✅ |
| 新建报告 | ✅ | ✅ | ✅ |
| 编辑/生成/删除自己创建的报告 | ✅ | ✅ | ✅ |
| 管理本部门用户（添加/改角色/移除） | ❌ | ✅ | ✅ |
| 管理本部门全部报告 | ❌ | ✅ | ✅ |
| 外部邮箱白名单 / 系统配置 / 全部报告 | ❌ | ❌ | ✅ |

> 说明：所有登录用户都可以创建报告。普通用户创建的是**个人报告**；部门管理员和超级管理员还可创建**部门报告**。

## 二、账号：注册与登录

### 2.1 注册账号
在登录页点击「**注册**」，进入注册表单：

| 字段 | 要求 | 示例 |
|---|---|---|
| 用户名 | 3–50 位；中英文、数字、下划线；全平台唯一 | `zhangsan`、`张三2026` |
| 邮箱 | 合法邮箱格式；用于接收报告邮件，全平台唯一 | `zhangsan@company.com` |
| 密码 | 8–20 位 | `Abc@1234` |
| 确认密码 | 与密码一致 | — |
| 所属部门 | 从下拉列表选择你所在的部门 | 终端BG服务部 |

点击「注册」成功后，会自动跳转登录页并帮你预填用户名，输入密码即可登录。

> 注意：
> - 用户名**不支持空格、点号、连字符等符号**，也不支持纯数字以外的特殊字符
> - 邮箱一旦注册，可在「个人中心 → 个人信息」中自行修改

### 2.2 登录 / 退出
- **登录**：输入用户名和密码，点「登录」。若提示"账号或密码错误"请核对；连续失败无需担心，可找管理员确认账号状态
- **退出**：点击右上角头像 → 「退出登录」
- **忘记密码**：平台暂不支持自助找回，请联系**部门管理员或超级管理员**重置

### 2.3 登录过期
如果长时间未操作，系统会提示"登录已过期"，重新登录即可。

## 三、报告中心（首页）

进入「报告中心」，这是你管理所有报告的地方。

### 3.1 顶部标签页
按查看范围分四个页签（不同角色可见的页签不同）：

| 页签 | 内容 | 可见角色 |
|---|---|---|
| 我的报告 | 你自己创建的报告 | 所有人 |
| 部门报告 | 本部门创建的全部报告 | 普通用户、部门管理员 |
| 公开报告 | 全平台被设为公开的报告（可跨部门看） | 所有人 |
| 全部报告 | 全平台所有报告 | 超级管理员 |

点击页签即切换，系统会自动重新加载列表。

### 3.2 搜索与筛选
列表上方提供 4 种筛选方式，可组合使用：

- **标题搜索**：输入关键词后回车，按报告标题模糊匹配
- **标签筛选**：输入标签关键词实时过滤（创建报告时打的标签）
- **按部门筛选**：仅在「公开报告 / 全部报告」页签下出现，可只看某部门的公开报告
- **状态筛选**：按报告状态过滤

### 3.3 报告卡片与状态
每个报告以**卡片**形式展示：标题、描述、部门/创建人、状态标签、版本号、更新时间、标签等。

状态标签含义：

| 状态 | 含义 | 你能做什么 |
|---|---|---|
| 草稿 | 已保存配置但未生成过 | 进入编辑，补充后生成 |
| 生成中 | AI 正在生成（可能排队中） | 可进详情页看进度，可终止 |
| 已完成 | 生成成功，有内容可看 | 查看/导出/发送 |
| 失败 | 生成出错 | 进详情看原因，修改后重新生成 |
| 超时 | 超过生成时限被强制终止 | 重新生成 |
| 已终止 | 手动终止 | 重新生成 |

### 3.4 分页
列表底部可翻页，右上角可切换每页显示条数（默认 20 条）。

### 3.5 新建报告
- 右上角「**+ 新建报告**」按钮，所有登录用户都可使用；普通用户创建的是个人报告，部门管理员/超管还可创建部门报告
- 点击任意卡片进入**报告详情页**

## 四、创建报告（三步向导详解）

点击「新建报告」进入三步向导：**基本信息 → 模块配置 → 预览与发布**。顶部可点击步骤条切换（前两步未完成时会校验）。

### 4.1 第 1 步：基本信息

| 字段 | 必填 | 说明 |
|---|---|---|
| 报告标题 | ✅ | 例如「8月终端服务质量月报」，用于列表展示和邮件标题 |
| 报告类型 | ✅ | 「个人报告」或「部门报告」；**部门报告仅部门管理员/超管可选**，且强制对部门内公开 |
| 报告描述 | 否 | 一句话说明报告用途，展示在卡片上 |
| 报告风格 | 否 | 默认「科技蓝」；下拉可选内置风格或你的自定义风格。点右侧「管理」可打开风格管理 |
| 标签 | 否 | 回车添加多个标签，用于列表筛选检索 |
| 公开到平台 | 否 | 仅对**个人报告**生效：开启后其他部门也能在「公开报告」看到 |

填完后点「**下一步：模块配置**」。

### 4.2 第 2 步：模块配置

报告的核心是一个或多个**模块**，每个模块 = 一个独立的 AI 分析任务。先点「**+ 添加模块**」，弹出「配置模块」表单。

#### 模块列表管理
- 添加后模块显示在列表中，按从上到下顺序执行
- 每个模块可「编辑」「删除」；列表可直观看到模块标题、模型、调度、关键词

#### 模块表单字段详解

**① 模块标题**（必填）
给这个分析任务起名，会作为报告正文的小节标题。

**② 模型配置**（必填）
告诉 AI 用哪个模型来生成：
- **服务商**：昇腾（华为云MaaS/MindIE）、OpenAI、Anthropic（Claude）、自定义（OpenAI 兼容）
- **API 地址**：模型服务的接口地址
- **API Key**：接口密钥（保存后不回显）
- **模型名称**：如 `gpt-4o`、`claude-3-5-sonnet`
- **参数**：温度（Temperature，0–1，值越大回答越随机）、最大输出长度（Max Tokens）
- **连接测试**：填好后点「连接测试」，显示"连接成功 + 延迟"即表示模型可用

**③ 关键词**
要 AI 重点分析的主题词，多个用回车分隔，会自动加入提示词。

**④ 查询 Prompt**（给 AI 的分析指令）
- 可点「快速插入模板」选用预设模板（行业舆情分析 / 服务质量报告 / 竞品监测）
- 支持占位符：`{keywords}`（自动替换成关键词）、`{urls}`（自动替换成数据源地址）
- 不填时系统会使用兜底提示词

**⑤ 输出格式**：Markdown 文本 / JSON 结构化

**⑥ 数据源**（**可选**）
- 逐条填写需要抓取的网页 URL（每条必填，可多条、可全部删除）
- 留空时：AI 仅凭 Prompt 和关键词生成（**没有外部资料依据**）
- 填了 URL：生成时先抓取这些页面内容，再交给 AI 分析
- 「引用数据源凭证」：需要登录/代理才能访问的网站，选你保存的抓取凭证
- 抓取参数：超时（秒）、失败重试次数、正文截断长度（2000/5000/10000，内容太长会被截断）

**⑦ 调度配置**（定时自动生成）
- 手动：仅在你点击生成时执行
- 每日/每周/每月：设置时间点（时/分，每周选星期，每月选日），系统按 Cron 自动触发
- 设置后会实时生成 Cron 表达式

保存后回到模块列表，可继续添加更多模块或点「下一步：预览与发布」。

### 4.3 第 3 步：预览与发布

- 页面展示报告完整配置的 **JSON 预览**（基本信息 + 模块配置），方便检查
- 两个按钮：
  - 「**保存草稿**」：只保存配置，不生成
  - 「**保存并生成报告**」：保存并立即开始 AI 生成，页面出现**生成进度卡片**
- 生成进度卡片：显示进度条与阶段（抓取→构建→调用模型→存储），可随时「**终止生成**」
- 生成完成后自动跳转到**报告详情页**

## 五、报告详情页（每个按钮都讲）

从报告中心点击任一报告进入详情页。页面分为**主内容区**和**右侧历史版本区**。

### 5.1 顶部标题栏
- 报告标题 + 状态标签（草稿/生成中/已完成/失败/超时/已终止）
- 右上角为操作区（部分按钮仅**报告创建者**可见）

### 5.2 右上角操作区（从左到右）

| 按钮 | 说明 | 可见性 |
|---|---|---|
| 风格下拉框 | 切换报告排版风格（科技蓝/商务灰/清新绿/学术/暗黑/自定义），**切换后当前版本立即按新风格渲染，无需重新生成** | 创建者 |
| 编辑 | 回到三步向导修改基本信息/模块配置 | 创建者 |
| 生成 | 触发 AI 重新生成（配置未变会覆盖当前版本，配置变了会累加 V+1） | 创建者 |
| 终止 | 生成过程中点此停止 | 创建者 |
| 导出 | 导出当前版本为 **PDF / Word / Markdown** | 所有人 |
| 发送邮件 | 把报告通过邮件发送给指定收件人（见第六章） | 所有人 |
| 发送记录 | 跳转到该报告的邮件发送记录 | 所有人 |

> 生成过程中，页面顶部会显示**实时进度条**（WebSocket 推送，断线时自动轮询兜底）。

### 5.3 主内容区
- 展示当前版本的报告正文：摘要 + 各模块小节（支持 Markdown 渲染、代码高亮）
- 正文样式跟随报告当前风格（颜色/字体/行距等）

### 5.4 历史版本（右侧）
每次生成成功都会留下一个历史版本，右侧时间线按时间倒序展示：

| 操作 | 说明 |
|---|---|
| 查看 | 点击时间线中的版本，主区域即切换到该版本内容（版本号与生成时间会标注） |
| 对比 | 点「对比」选择两个版本（版本 A/B），用 Diff 视图查看差异（新增/删除内容高亮） |
| 回滚 | 非当前版本上点「回滚」，把报告内容恢复为该版本（生成一条新版本记录） |

> 提示：历史版本保留了生成时的风格快照，查看旧版本时正文按当时风格渲染。

## 六、用邮件发送报告

### 6.1 发送邮件
报告详情页点「**发送邮件**」，弹出发送窗口：

| 设置项 | 说明 |
|---|---|
| 收件人 | 逗号分隔输入多个邮箱；也可点「**从通讯录选择收件人**」选平台内同事（自动填入）；点「**添加我**」填自己的邮箱 |
| 附件格式 | PDF / Word / Markdown，可多选 |
| 版本号 | 下拉选择要发送的版本（默认最新） |
| 定时发送 | 打开开关后可选择未来时间，到点自动发送；不开则立即发送 |

**外部邮箱白名单**：收件人若是**非平台内部域名**（如 `@partner.com`），该域名必须在管理员配置的「外部邮箱白名单」中，否则发送会被拦截并提示。

### 6.2 邮件发送记录
左侧菜单「**邮件发送记录**」可查看所有发送任务：

- 列表字段：报告、收件人、附件格式、版本、状态、触发方式（手动/定时）、创建时间、发送时间
- **状态**：排队中 / 发送中 / 已发送 / 失败 / 已终止
- 点击行展开可查看**每个收件人**的发送结果和失败原因
- 有任务在发送时页面每 3 秒自动刷新，并显示进度
- 操作：
  - 「**终止**」：排队中或发送中的任务可终止（已发出的收件人不撤回）
  - 「**重发**」：已结束（发送/失败/终止）的任务可按原收件人/格式/版本重新发送

### 6.3 收不到邮件的排查顺序
1. 确认任务状态是「已发送」且收件人行显示成功
2. 检查收件人邮箱是否在**外部邮箱白名单**（联系管理员）
3. 查看垃圾邮件箱
4. 联系管理员确认系统是否为「模拟发送」模式（开发/测试环境可能不真正发信）

## 七、个人中心

点击右上角头像 → 「个人中心」，有 4 个标签页。

### 7.1 数据源凭证
用于报告抓取**需要登录/代理/特殊请求头**的网页：

| 字段 | 说明 |
|---|---|
| 凭证名称 | 自定义名字，如「内网BI系统」 |
| 代理 | 代理服务器地址，格式 `http://账号:密码@地址:端口`，用于公司内网访问外网 |
| Cookie | 网站的登录 Cookie（登录目标网站后从浏览器复制），用于抓取需登录的页面 |
| 自定义请求头 | JSON 格式，如 `{"Referer": "https://www.example.com"}`，用于通过反爬校验 |

- 凭证**仅自己可见**，列表展示时敏感字段会自动脱敏（只显示前 12 位）
- 创建后在「添加模块 → 数据源 → 引用数据源凭证」中选择使用

### 7.2 报告风格
- 点「管理报告风格」可查看内置风格和你的自定义风格
- 内置风格：科技蓝（默认）/ 商务灰 / 清新绿 / 学术 / 暗黑
- 可「新建自定义风格」：设置主色、背景色、字体、标题字号、正文大小、行距、表格/引用/代码配色等，实时预览
- 部门管理员可将自定义风格「设为部门共享」，供同事选择

### 7.3 个人信息
- 查看用户名、邮箱、部门、角色
- 「**修改**」按钮可自助修改邮箱（新邮箱不能被其他账号占用）

### 7.4 主题设置
- 浅色 / 深色界面切换，实时生效，并记住你的选择

## 八、部门管理（部门管理员）

左侧菜单「部门管理」进入本部门用户管理页：

| 操作 | 说明 |
|---|---|
| 添加用户 | 用户名（规则同注册）、邮箱、角色（普通用户/部门管理员）、初始密码（可选） |
| 修改角色 | 把用户调整为普通用户/部门管理员（不能降级自己） |
| 移除用户 | 将用户移出部门（软删除，其报告保留） |

> 权限边界：部门管理员只能管理**本部门**用户，不能操作超级管理员账号。

## 九、系统管理（超级管理员）

左侧菜单「系统管理」，共三个页签：

### 9.1 外部邮箱白名单
- 发送邮件到**外部域名**（如 `@partner.com`）前，该域名必须在此添加（输入域名如 `partner.com` 或 `@partner.com`）
- 平台内部域名（如 `@insight.local`）无需加白名单

### 9.2 系统配置
- **SMTP 配置**：邮件服务器的地址、端口、账号、密码、发件人、TLS；可「测试 SMTP 连接」验证；密码留空表示不修改
- **任务配置**：最大并发生成任务数（默认 5）、单个生成任务超时时间（默认 1800 秒）
- **邮件发送模式**：模拟发送开关——**开发/测试建议开启**（不真正发信）；**正式使用请关闭**并配置好 SMTP
- 保存后立即生效（并发数需重启后端生效）

### 9.3 全部报告
- 全平台报告总览：标题搜索、按部门筛选，查看各部门报告情况

## 十、常见问题 FAQ

**Q1：报告生成失败/超时怎么办？**
排查步骤：
1. 详情页看是否提示具体错误（模块失败会标注失败原因，不影响其他模块）
2. 检查模块「模型配置」：API 地址、密钥、模型名是否正确，点「连接测试」
3. 检查「数据源」URL 是否能直接访问；需要登录的页面记得引用数据源凭证
4. 单个任务超过超时时间（默认 30 分钟）会被强制终止，可减小数据源数量或截断长度后重试

**Q2：邮件显示"已发送"但我没收到？**
可能原因按顺序排查：
1. 系统处于「模拟发送」模式（开发/测试环境）——联系管理员关闭
2. 收件人是外部邮箱但域名不在白名单——联系管理员添加
3. 进了垃圾邮件箱
4. 发件人地址被对方邮件服务器拦截（如 SPF 校验），联系管理员核对发件人配置

**Q3：抓不到网页内容？**
很多网站需要登录态或校验请求头。在「个人中心 → 数据源凭证」创建包含 Cookie/请求头/代理的凭证，再到模块配置「引用数据源凭证」。也可以调大超时/重试，或把截断长度从 2000 调高到 5000/10000。

**Q4：为什么我点不了某报告上的「编辑/生成/删除」？**
报告写操作仅**创建者本人**可执行（部门管理员/超管也只对**自己创建**的报告可编辑）。查看、导出、发送邮件对部门内成员开放。

**Q5：用户名/密码规则？**
用户名 3–50 位，中英文/数字/下划线；密码 8–20 位。注册时按提示填写即可。

**Q6：风格切换为什么没有立刻生效？**
当前版本的风格切换是即时生效的（无需重新生成）；但如果你在查看**历史版本**，正文按该版本生成时的风格渲染，切换只影响当前版本。重新生成后新版本应用最新风格。

**Q7：定时生成/定时发送为什么没触发？**
定时功能依赖平台后台调度服务（进程内调度器或 Celery Beat）。如果本机服务重启后未恢复，定时任务不会执行——请联系管理员确认调度服务运行正常。

**Q8：有疑问找谁？**
- 账号、权限、创建报告：找**部门管理员**
- 白名单、SMTP、系统配置、定时服务：找**超级管理员**
